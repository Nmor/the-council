# Hiring Process

> **Size budget: 8 KB** — `token-budget.mjs --check`.

Principal-level hiring system design — role definition, sourcing, structured interviewing, bar-raising, calibration, offer, and onboarding. Treat hiring as the highest-leverage decision an organisation makes and engineer the process to minimise predictable failure modes (unstructured interviews, halo effect, like-me bias, rushed decisions, weak onboarding).

## Working procedure

1. Establish the relevant mode and existing evidence; do not repeat completed intake.
2. Use job-related evidence, consistent rubrics and applicable discrimination/privacy requirements. Keep candidate data authorized and minimize retention. Do not infer protected attributes or delegate decisions to unvalidated scoring.
3. Read only the corresponding sections below before applying their examples.
4. Verify the result with meaningful positive, negative and failure controls. Record actual outcomes, limitations and next action.
