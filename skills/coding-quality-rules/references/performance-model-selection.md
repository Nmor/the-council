# Models, tools and context

> **Size budget: 8 KB** — `token-budget.mjs --check`.

Use the [principal quality contract](../../../rules-library/council-detail/principal-level-mandate.md#evidence-based-tools-and-dependencies)
to select tools and dependencies by verified fitness, support and representative
evidence. Do not choose weaker diagnostics or mock an essential integration simply
because the required check is harder. Report an unavailable required check honestly.

Model selection belongs to the [canonical policy](../../../rules/common/model-tier-selection.md).
Respect the user's choice, supported runtime and task requirements. Do not duplicate
model ladders here or claim a dated alias always names a particular model. Claude
source `model:` frontmatter is a convention, not permission to change Codex's model.
Native helpers inherit the parent unless an explicitly supported, authorized override
applies. Do not invent an unavailable tool, extended-thinking switch or automatic
hook model transition; report constraints and keep high-risk verification explicit.

Keep active context focused on the current task, decisions and necessary inputs.
Search before reading, use bounded sections and write verbose evidence to files.
Update the existing plan's compact handoff at milestones. Context pressure is not
permission to skip tests or security checks, create another plan, kill another session
or spawn a team. A concrete independent helper must obey active delegation limits.
No guessed remaining-context percentage is required to enforce this discipline.
