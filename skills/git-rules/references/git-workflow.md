# Git and PR workflow

> **Size budget: 8 KB** — `token-budget.mjs --check`.

Read the canonical [git workflow](../../../rules-library/common/git-workflow.md)
for identity/signing, review baselines, commit conventions, PR descriptions and
feature verification. It owns the workflow for both Claude Code and Codex; this
reference deliberately does not copy a second version.

Use the actual review diff and evidence tied to its inputs. PRs explain the final
behavior and material decisions, with completed, failed and outstanding verification
clearly separated. Existing user authorization governs commits, pushes and delivery;
neither a skill nor this reference grants additional permission.
