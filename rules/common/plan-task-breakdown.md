# Useful planning

> Size budget: 2 KB.

For multi-step work, keep small outcome-based tasks in the existing authoritative
plan. Each substantive task has a stable ID, type, priority, status, owned scope,
needed context, dependency IDs, acceptance and verification. Use the shared contract
below across Claude, Codex, specialists and trackers; preserve existing IDs. Split
independent outcomes or unresolved decisions, not code from its necessary tests.

Keep only the active task and a few ready next tasks in the live tracker. Store the
full backlog and a compact resume handoff in the plan. Record successful evidence
before marking done. Preserve integration work. A routine fix needs no new plan,
fixed task count, mandatory hierarchy, ADR or exhaustive questionnaire. Do not
expand tasks only to give every division a role.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/plan-task-breakdown.md).
Do not preload it for unrelated work.
