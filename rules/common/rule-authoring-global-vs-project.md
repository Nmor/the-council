# Rule scope

> Size budget: 2 KB.

Put general, proven guidance in the shared Council; keep repository commands, private paths,
customer data and personal preferences local. A new global rule must justify its recurring context
cost. Put detailed examples in on-demand references and give the short entrypoint a clear activation
condition.
