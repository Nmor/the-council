# User-facing quality

> Size budget: 2 KB.

For changed UI flows, check usability, accessibility, consistency, error/empty/loading states and
the project's design conventions. Use relevant UX specialists when the problem warrants them. Do not
redesign unrelated screens or impose a new visual style to satisfy a generic aesthetic checklist.

UI work is layered: direction from `taste-skill` (style engine; marketing/landing surfaces) with
`frontend-design` as baseline; platform implementation from `modern-web-guidance`;
motion/interaction from the Emil Kowalski skills or `/impeccable polish`; pre-ship audit via
`/web-interface-guidelines` or `/impeccable audit`; `ui-ux-pro-max` is a lookup database only.
**Precedence on conflict:** project tokens → the brief → Emil skills (motion/app UI) → taste-skill
(marketing direction) → pro-max (lookup); design verdicts in council-rules "Settled debates" govern.
Generic AI-styled output (default gradients, emoji-stuffed cards, lorem content) fails this gate.
