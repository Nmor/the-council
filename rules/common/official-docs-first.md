# Targeted primary sources

> Size budget: 2 KB.

For changed external contracts, uncertain technical facts and time-sensitive integrations, check the relevant primary documentation. Reuse a cited source already verified for the same contract/version. Do not perform a fresh ecosystem survey for a status answer, formatting change or unrelated code edit. Platform and runtime environments are external contracts too — CI runner images, OS text defaults, workflow and hook schemas — verify them at the pinned version, and delegate the lookup to a docs agent when one exists. Separate observed behavior from inference.

For relevant detailed procedures and examples, read
[the reference](../../rules-library/council-detail/official-docs-first.md).
Do not preload it for unrelated work.
