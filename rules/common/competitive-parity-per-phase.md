# Parity checks

> Size budget: 2 KB.

For migrations and explicit parity work, maintain a capability/evidence ledger in the existing plan.
Compare the changed capability and affected integration paths; do not repeat a full competitive
survey at every phase. Reopen an accepted comparison only when scope, upstream contracts or evidence
changes.
