# Scope and context discipline

> Size budget: 2 KB.

Reuse existing primitives. Add only behavior needed for the requested outcome; avoid speculative APIs, ceremony and duplicated documentation. Code YOUR change introduces with no caller is bloat; code you INHERITED with no caller is a question, not a verdict — triage what it is for before removing it, because unfinished is not useless. No delete lands until an alternative that covers the use case is NAMED and shown to cover it. Search before reading large files, load only relevant reference sections, and summarize verbose tool output without losing failures. Do not read the whole historical plan or entire Council library into every agent. Keep the eager Floor under the independent context budget.
