# Project isolation

> Size budget: 2 KB.

Keep plans, runtime logs, audits and personal identifiers out of public source. Preserve the
canonical artifact layout. Retain audit evidence while a check, review or unresolved finding needs
it; record outcomes in the plan, then remove consumed scratch with no active consumer. Shared rules
remain project-independent.
